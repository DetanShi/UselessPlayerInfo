# UselessPlayerInfo

A simple program that shows some useless info on your character's current location. `/openmenu` and `/helloworld` are the current commands.

## Installing as a third-party plugin

1. In-game, open Dalamud Settings -> Experimental -> Custom Plugin Repositories.
2. Add this URL and hit the `+`, then save:
   ```
   https://raw.githubusercontent.com/DetanShi/UselessPlayerInfo/main/repo/pluginmaster.json
   ```
3. "Useless Player Info" will show up in the Plugin Installer under the "Custom Plugins" tab.

## Publishing a new version

Building in `Release` (via `build.bat` or `dotnet build -c Release`) produces a ready-to-ship `latest.zip` under `bin/Release/net10.0-windows7.0/UselessPlayerInfo/`, generated by DalamudPackager.

To publish an update:

1. Bump `AssemblyVersion`/`FileVersion` in [UselessPlayerInfo.csproj](UselessPlayerInfo.csproj) and `AssemblyVersion` in [repo/pluginmaster.json](repo/pluginmaster.json) (they must match).
2. Build in Release.
3. Create a new GitHub Release (mark it "Latest") and upload `latest.zip` as a release asset named exactly `latest.zip` — the download links in `pluginmaster.json` point at `.../releases/latest/download/latest.zip`, which always resolves to the newest release.
4. Commit and push the updated `repo/pluginmaster.json` so Dalamud picks up the new version.
